# Internationalization

TurkDemy enables Django `LocaleMiddleware` and supports:

- English (`en`)
- Persian (`fa`)
- Turkish (`tr`)
- Arabic (`ar`)

`LOCALE_PATHS` points to the repository-level `locale/` directory.

Public and admin URLs are wrapped with Django `i18n_patterns`.

Database-localized model fields (`name_en`, `name_fa`, etc.) are separate from
Django gettext translations used for interface text.
