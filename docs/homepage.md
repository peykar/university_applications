# Homepage

The TurkDemy homepage is a database-driven admissions/catalogue landing page.

It uses live database values for university/program/FAQ counts, featured
universities, active program counts, popular programs, minimum tuition,
popular study fields and FAQ preview.

Hero search redirects to the program catalogue search.

If a high-priority active university has a banner, it becomes the hero
background; otherwise TurkDemy uses its navy/red gradient.

The visual direction combines a richer marketing experience with practical
catalogue usability while keeping TurkDemy's own identity.
