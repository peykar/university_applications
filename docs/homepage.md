# Homepage

The TurkDemy homepage is a database-driven admissions/catalogue landing page.

It uses live database values for university/program/FAQ counts, featured
universities, active program counts, popular programs, minimum tuition,
popular study destinations, popular study fields and FAQ preview.

Hero search redirects to the program catalogue search.

If a high-priority active university has a banner, it becomes the hero
background; otherwise TurkDemy uses its navy/red gradient.

The visual direction combines a richer marketing experience with practical
catalogue usability while keeping TurkDemy's own identity.

## Study destinations

Between Featured Universities and study-field discovery, the homepage shows up to five
qualifying Cities ordered by active University coverage, then active Program coverage. Each
card links directly to the City's canonical `/universities/cities/<slug_en>/` landing page,
shows localized City name plus active University/Program counts, and reuses the curated City
banner and localized alt text when available. On mobile the cards form a horizontal swipe
row to keep the homepage compact.
