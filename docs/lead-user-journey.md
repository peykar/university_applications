# Applicant User Journey

```text
Browse universities/programs
        ↓
Open Program
        ↓
Apply / I'm interested
        ↓
Login / Register (required)
        ↓
Choose existing applicant
or create another applicant
        ↓
Applicant workspace
 ├── profile
 ├── study preferences
 ├── program interests
 ├── staff/system suggestions
 ├── documents
 └── messages
        ↓
Staff/system review
        ↓
Suggestions sent
        ↓
User likes / declines suggestions
        ↓
Documents + messaging
        ↓
Staff/system validates/finalizes
        ↓
Student created
        ↓
Qualified program interests
        ↓
Formal Applications
```

Customers never need to know the CRM term `Lead`; the public UI calls these
records **Applicants**.
